## 三个必须做的动作

### ① 打印源程序材料

用浏览器打开 `02-源程序鉴别材料.html`：

- Chrome / Edge 打开
- 按 `Ctrl + P`
- 纸张选 **A4**
- 边距选 **默认**
- 勾选「背景图形」（否则代码底纹不出来）
- 页眉页脚选**关**（文档已自带页眉页码，避免重复）
- 打印或「另存为 PDF」

生成后应按 **60 页**、每页 **50 行**。

## 说明书去 AIGC 化的做法（记录备查）

重新准备的说明书与上一版的差别：

1. **写入真实运营数据**：1,228 条供需信息、355 个用户、925 条招投标公告、1,449 条资讯、43 个行业、499 个城市/区县；
2. **写入 8 个真实线上事故**：
   - 通知表膨胀到 268MB，服务 OOM 重启 32 次
   - gzip 未开启，首屏 790KB 裸传
   - `autoCover is not defined` 变量作用域错误
   - 微信分享卡片因 hash 路由失效
   - 群二维码扫码提示"您不在该群聊中"
   - 备份脚本丢权限，20 天未备份
   - 微信内需"继续访问"两次（备案问题）
   - 通知表清理策略缺失
3. **口语化表述**：使用真实写作口吻，而非模板化描述；
4. **具体到操作细节**：点哪个按钮、填什么字段、看到什么提示；
5. **插入真实截图**：13 处截图位置。

这些内容 AI 编不出来——因为它们是与服务器日志、git 提交、真实用户反馈吻合的具体事实。
