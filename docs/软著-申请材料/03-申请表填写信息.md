## 五、主要功能与技术特点（约 300 字，可直接粘贴）

**主要功能**

本软件是一个面向产业供需对接的信息发布与服务管理平台，由服务端与浏览器客户端两部分构成。核心功能包括：多类型信息发布（项目、活动赛事、贸易采供、科技成果、招投标、短视频、直播等 10 类板块）；基于大模型的内容解析与要素抽取，可自动完成标题生成、正文理解、图片文字识别、金额与地区提取、联系方式脱敏；按行业与地区的内容匹配与推送；关键词检索与语义检索；招投标公告聚合与地区分类；行业资讯采集与每日摘要；短视频上传与自动转码；群组沟通与用户关系链管理；推荐码邀请机制；服务商入驻；以及用户管理、内容审核、板块排序、数据统计等管理后台功能。

**技术特点**

（1）服务端采用零第三方依赖架构，仅使用 Node.js 内置模块实现 HTTP 路由、数据存储、任务调度与鉴权，部署体积小、依赖风险低；
（2）数据层采用 JSON 文件集合存储并配合内存缓存与定时落盘，在中小规模数据下兼顾读写性能与运维简便；
（3）前端为无构建步骤的原生模块化架构，页面按需懒加载，配合 Service Worker 实现离线缓存与版本更新；
（4）针对长延迟、稀疏反馈的产业撮合场景，设计了分层反馈采集与内容匹配机制；
（5）实现了分享链接的服务端动态渲染，解决单页应用在社交平台分享时无法生成定制卡片的问题。
