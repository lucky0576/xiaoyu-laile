### 关键结论

```
✅ 好消息：域名在腾讯云 DNSPod，直接在腾讯云备案系统提交即可，无需转移
❌ 坏消息：现在的香港服务器永远无法备案
```

ICP 备案的监管对象是「**在大陆境内提供互联网信息服务、且使用大陆境内服务器**」的网站。
香港机房不在这套管理体系内，所以既不是"不用备案"，而是**"备不了案"**。

这也解释了现在两个问题：
- 手机打开要点两次「继续访问」（无备案号的境外域名被安全拦截）
- 微信分享卡片不稳定

## 五、技术侧：三步走

### 第 0 步：准备好（已完成）

```bash
# 备案期维护页（已部署到线上，可随时访问验证）
public/icp-pending.html

# 一键迁移脚本（已写好并通过语法检查）
scripts/migrate-to-mainland.ps1
```

### 第 1 步：备案期部署（现在就能做）

```powershell
# 在上海/杭州的腾讯云服务器上部署
.\scripts\migrate-to-mainland.ps1 `
    -Server 1.2.3.4 `
    -Password 你的服务器密码 `
    -Phase icp `
    -WithData
```

脚本会做：
1. 检测服务器是否真在中国大陆
2. 本地打包 → 上传 → 解包到 `/opt/xiaoyu-laile`
3. 安装 Node 20 / nginx / certbot
4. 从香港老服务器拉历史数据（379MB）
5. 配置 systemd 服务并启动
6. 配置 nginx：**80 端口只返回「网站备案中」页**
7. 健康检查

**结果**：
```
对外 80  → 「小鱼来了 · 网站备案中」页
内部 8787 → 主站正常运行（可用 IP 直连验证）
```

### 第 2 步：切 DNS（备案终审前）

```
腾讯云 DNSPod → 域名解析 → xiaoyulaile.online
把 A 记录从 154.221.23.7 改为新服务器 IP
```

> 管局终审时会实际访问域名核查，所以必须在终审前完成解析切换。

### 第 3 步：备案通过后切全站

```powershell
.\scripts\migrate-to-mainland.ps1 `
    -Server 1.2.3.4 `
    -Password 你的服务器密码 `
    -Phase live
```

脚本会：
1. 重写 nginx 为「HTTP 301 → HTTPS + 443 反代主站」
2. `certbot` 自动申请 Let's Encrypt 证书
3. 配置 HSTS、安全响应头
4. 保留 502/503 维护页兜底

## 七、风险与应对

### ① 备案期间主站断档 3~7 天

**原因**：管局核查要求域名解析到大陆服务器。

**降低影响**：
- 提前在朋友圈/微信群公告：「网站备案升级，预计 X 月 X 日恢复」
- 把老客户的紧急联系方式（手机/微信）先发出去
- 选择业务低峰期（比如周末前提交）

### ② 网站名称/服务内容被打回

**最常见原因**：服务内容选了「论坛/社区/BBS」。

**对策**：选「其他」，备注写「行业信息展示与对接平台」，并主动说明有 AI+人工双重审核。

### ③ UGC 内容被要求补充材料

管局可能要求：
- 内容审核机制说明 → ✅ 你有 AI 审核 + 管理后台人工复核
- 违法信息处置流程 → ✅ 有举报/下架功能
- 用户实名 → ✅ 手机号注册

**建议提前准备一份《内容审核机制说明》文档**（我可以帮你写）。

### ④ 备案后内容变更需重新备案

备案通过后，如果：
- 改网站名称
- 改服务内容（比如加了论坛/直播/电商）
- 换服务器（换接入商）

都要做**变更备案**。所以备案时把服务内容写全一点。

### ⑤ 老用户数据迁移

`-WithData` 会自动迁移 `/opt/xiaoyu-laile/data`（379MB）。
迁移后建议在旧服务器上**保留 7 天只读**，出问题能快速回滚。
