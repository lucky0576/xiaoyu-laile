## 二、`.icu` 域名能不能备？—— 有争议，必须实测

查到两种说法，都有来源：

**说可以备案的：**
- 工信部 2019-05-10 正式审批 `.icu`，在中国大陆注册的 `.icu` 可进行工信部域名备案 — [维基百科 `.icu`](https://zh.wikipedia.org/zh-hans/.icu)
- 多个备案服务商的「可备案后缀」列表里包含 `.icu` — [wvidc](https://www.wvidc.com/help/hlp_dtl_10000287.html)、[凡科](https://www.fkw.com/helpCenter/articleDetail.jsp?blogId=1114176)

**说不能备案的：**
- 百度智能云文档把 `.icu` 列入「不能备案域」—— [百度智能云](https://cloud.baidu.com/theme/Y/3547094-70)
  （注：该文是**北京管局**规则，各省要求不同）

**结论**：工信部层面 `.icu` 是批准后缀，但**浙江管局 + 具体云服务商的备案系统是否接受，必须实测**。

**怎么实测（5 分钟，不花钱）**：
1. 注册阿里云 / 腾讯云账号（免费）
2. 进「ICP 备案」→ 新增网站 → 输入域名 `xiaoyulaile.icu`
3. 系统如果提示「该域名后缀不支持备案」→ 换域名
4. 能进到填主体信息那一步 → 说明后缀没问题

**如果 `.icu` 不行，备选**：`.com` / `.cn`（约 60-80 元/年，这两个 100% 可备）
