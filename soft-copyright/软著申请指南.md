## 一、先搞清楚：软著是什么，值不值

**软件著作权登记**是国家版权局（中国版权保护中心）对软件著作权归属的**初步证明**。

| 不是 | 是 |
|---|---|
| 不是专利，不审查技术是否"新颖" | 形式审查，只看材料是否齐全合规 |
| 不是商标 | 保护的是**代码本身**的著作权 |
| 不是强制要求 | 但对外证明"这软件是我开发的"时，是最硬的证据 |

### 对你们的价值

1. **融资、尽调必备** —— 投资方查知识产权时，软著是最基础的资产证明
2. **高新企业认定加分** —— 申请国家高新技术企业，知识产权是硬指标
3. **防止被抄** —— 有登记证书，维权时举证成本极低
4. **政府项目申报** —— 多数科技项目要求有自主知识产权
5. **可在网站/名片上标注** —— "已获国家软件著作权登记"，提升可信度

### 费用与周期

| **官方费用** | **0 元**（2017 年起国家取消软著登记费） |

## 四、申请流程（自己办）

### 第 1 步：注册账号

```
中国版权保护中心 · 软件著作权登记系统
https://register.ccopyright.com.cn/
```

- 实名认证（个人或企业，建议用企业主体）
- 需要上传营业执照

### 第 2 步：在线填报

填写上述信息，上传两份文档：

```
源程序文档        → 上传 小鱼来了AI信息发布平台V1.0-源程序.docx
软件说明书        → 上传 小鱼来了AI信息发布平台V1.0-软件说明书.docx（补完截图后）
```

### 第 3 步：等待受理与审查

| 阶段 | 时间 |
|---|---|
| 形式审查（材料是否齐全） | 5~10 工作日 |
| 受理通知 | 审查通过后下发 |
| 登记公告与发证 | 约 30~45 工作日总计 |

### 第 4 步：领取证书

- 电子证书：系统内下载
- 纸质证书：可申请邮寄

## 五、常见被退回原因（提前避开）

| 原因 | 说明 | 我们的状态 |
|---|---|---|
| 源程序不足 60 页 | 每页 50 行，不足则全提交 | ✅ 正好 60 页 |
| 说明书与源程序功能对不上 | 说明书写的功能代码里没有 | ✅ 说明书按实际功能写 |
| 软件名称含英文/特殊符号 | 如"小鱼2.0 Pro" | ✅ 纯中文 |
| 名称与已有软著重名 | 需查重 | ⚠️ 建议先查一下"小鱼来了"是否已被注册 |
| 开发完成日期晚于申请日期 | | ✅ 填 2026-10-26 |
| 权利归属不清 | 多人开发未签协议 | ✅ 独立开发 |

### 建议先查重

```
中国版权保护中心 → 软件公告查询
https://register.ccopyright.com.cn/query.html
搜索关键词：小鱼来了
```

如果没有重名，直接申请。如果已被注册，改名为：

```
小鱼来了产业信息智能发布平台
小鱼来了AI供需对接平台
```
