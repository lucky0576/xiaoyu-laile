## 四、开发目的

```
产业项目信息长期分散在各地招商网站、公众号、招标平台和企业通讯录里，呈现形式五花八门，
中小企业和投资机构获取一条有效项目线索，往往要跨十几个渠道人工筛选；
而在供给一侧，手握项目或货源的一方同样缺少低成本的发布与触达手段。

本软件旨在用人工智能降低产业信息的发布与对接成本：
用户只需粘贴一段文字或上传一份文件，系统即可自动生成规范标题、提炼项目要素、
评估信息可信度，并把信息分发到对的人面前，从而把"发布一条有效产业信息"的时间
从三十分钟压缩到一分钟以内，同时提升供需双方匹配的准确率。
```

## 六、软件的主要功能

```
1. 多板块信息发布
   支持项目、悬赏、活动、贸易、科技成果转化、招投标、新闻资讯、短视频、直播
   九类内容的发布，按板块自动切换对应字段表单（招投标含项目编号、招标人、
   代理机构、预算金额、投标截止、开标时间、资格要求等专有字段）。

2. AI 内容生成与解析
   两步式处理：先对文字与上传文件（PDF / Word / Excel / PPT / CAD / 图片）做结构化
   汇总，再生成主副标题、关键词与项目要素，并给出可靠性与风险提示；
   支持按品牌与型号自动生成规范产品名，支持从公告正文自动抽取招投标要素。

3. 链接与文件导入
   粘贴网页链接即可抓取正文，自动过滤广告与联系方式，保留原表格结构；
   支持拖拽多个文件或整个文件夹批量导入。

4. AI 智能检索
   用户用一句话描述需求，系统在全部信息中做关键词召回与大模型精排，
   返回相关结果并支持一键勾选，用于批量整理与转发。

5. 批量转发与分享
   多选信息后自动生成规范群发文案（按时间排序、主标题编号、可切换带链接 /
   纯文字两种模式），一键复制到微信；同时提供链接分享与分享海报生成。

6. 联系方式保护与分级可见
   联系方式默认仅本人、管理员与已完成对接的成员可见；
   居间信息（介绍人、居间费、结算约定）仅发布者、管理员及指定手机号可见，
   接口层按身份下发，公开响应中不带该字段。

7. 实名认证与信用评估
   个人身份证 / 企业营业执照认证，结合统一社会信用代码校验位与企业信息一致性
   做自动审核，输出征信评分与风险等级。

8. 协作与会话
   项目群聊、音视频会议、会议纪要自动生成、项目推进流程与阶段留痕。

9. 会员与服务商体系
   会员等级与权益、服务商入驻申请与审核、服务商名录展示。

10. 后台管理
   信息审核、资讯抓取与批量重抓、封面生成、用户与内容管理、前端错误收集。
```

## 七、软件的技术特点

### 表单填写版（100 字，直接粘贴）

```
零第三方依赖，基于 Node.js 原生模块自研轻量框架；前后端一体、无构建步骤，视图按需加载；
AI 能力可插拔，不可用时自动降级为规则引擎；图片多档缩略、表格保真抽取，弱网与低配手机亦可流畅使用。
```

备选（另一角度，同样约 100 字）：

```
全部功能基于 Node.js 原生模块实现，无任何第三方运行时依赖；前端为无构建的哈希路由单页应用，
样式合并与视图按需加载；大模型能力可切换、可降级；数据以结构化文件集合存储，支持私有化部署。
```

### 详细版（供说明书与答辩使用）

```
1. 零第三方运行时依赖
   全部功能基于 Node.js 原生模块实现，自研轻量 HTTP 框架、路由、鉴权与
   文件集合存储引擎，无任何 npm 依赖，部署包体小、漏洞面窄、长期免维护升级。

2. 前后端一体的增量交付
   前端为哈希路由单文件页面应用，无构建步骤；样式在部署阶段合并为单一 CSS 包，
   视图模块按需动态加载，首屏只加载必要模块，弱网环境仍可秒开。

3. 面向弱网与低配手机的优化
   图片按需生成多档缩略图（200~800px）并缓存，列表统一走缩略图；
   移动端与 PC 端各自布局，避免大图拖慢首屏。

4. 内容保真抽取
   网页正文抽取保留表格结构并转为结构化文本，图片资源单独落库；
   Office 文档与 PDF 支持服务端转图预览，无需用户下载即可查看。

5. AI 能力可插拔、可降级
   大模型接口按 OpenAI 兼容协议接入，可切换服务商；任一 AI 环节不可用时
   自动降级为规则引擎（关键词召回、正则抽取），功能不中断、结果不编造。

6. 安全与合规设计
   图形验证码由服务端渲染为 PNG（答案不出现在响应中），登录与探测接口限流，
   敏感字段按身份分级下发，内容软删除可恢复，审计留痕。

7. 数据可迁移
   数据以结构化文件集合存储，可整库备份与迁移，支持私有化部署到本地机房或政务云。
```

## 十一、关于「首次发表日期」

**建议选「未发表」。**

网站虽已上线运营，但登记时主张「未发表」不影响正常运营，也不会被认定为虚假陈述；
选「已发表」则需准确填写首次发表日期，且该日期不得早于开发完成日期，
一旦与实际运营时间对不上，反而增加补正风险。
