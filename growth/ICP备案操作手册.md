# 小鱼来了 · ICP 备案操作手册

> 目标：把 `xiaoyulaile.online` 备案，消除浏览器「疑似风险内容」提示，并具备后续开通支付的前提。
> 周期：注册主体 1 周 + 备案 7~20 个工作日。
> 费用：备案免费；大陆服务器 60~100 元/月；域名已有。

---

## 一、先做决定：用什么主体备案

| 方案 | 材料 | 优点 | 缺点 |
|---|---|---|---|
| **个体工商户** | 营业执照 | 注册快、便宜 | 办不了 ICP 许可证、不能融资、无限责任 |
| **有限责任公司** | 营业执照 + 法人身份证 + 章程 | 能融资、能办许可证、能开专票 | 注册慢一点、要记账报税 |

**我的建议：如果只为了消除浏览器提示 → 个体户够用；如果要融资/收费/投标 → 直接注册公司。**

> ⚠️ **备案主体必须与域名持有者一致。** 域名现在的实名认证主体是谁？必须统一。

---

## 二、需要准备的材料清单

```
□ 营业执照（个体户或公司）
□ 法人 / 经营者身份证 正反面
□ 域名证书（在域名注册商后台下载）
□ 大陆服务器（阿里云/腾讯云，购买 ≥3 个月）
□ 手机号（法人本人，需接验证码）
□ 邮箱（常用邮箱）
□ 紧急联系人信息（姓名、电话）
□ 网站备案信息真实性核验单（系统生成，需签字）
□ 若为公司：股东信息、法人手持身份证照片（部分省要）
```

**域名实名认证检查**：

```
阿里云/腾讯云 → 域名控制台 → 域名信息 → 实名认证状态
必须是「已实名」，且主体名称与备案主体完全一致。
不一致 → 先做域名过户（3~5 天）
```

## 三、买服务器（选型建议）

| 厂商 | 配置 | 价格 | 备注 |
|---|---|---|---|
| 阿里云轻量 | 2 核 2G / 40G / 3M | ~90 元/月 | 备案友好，需选「华东1（杭州）」或「华东2（上海）」 |
| 腾讯云轻量 | 2 核 2G / 40G / 4M | ~80 元/月 | 同上，选上海/南京节点 |

**注意三点：**

```
① 必须买 3 个月以上（备案要求）
② 必须选中国大陆节点（香港/海外不能备案）
③ 购买时用途选「网站」，不要选「游戏」「视频」等敏感类目
```

**备案期间服务器可以先不开站**，等备案通过再迁移。也可以先开着（见第八节）。

## 四、备案流程（以阿里云为例，腾讯云类似）

### 第 1 步：进入备案系统

```
阿里云 → 控制台 → 备案 → 开始备案
（或直接访问 beian.aliyun.com）
```

### 第 2 步：填写主体信息

| 字段 | 怎么填 |
|---|---|
| 主体类型 | 企业 / 个体工商户 |
| 主办单位名称 | 营业执照上的**完整名称**，一个字都不能差 |
| 证件号码 | 统一社会信用代码 / 注册号 |
| 证件住所 | 营业执照上的注册地址 |
| 通信地址 | 实际能收到信的地址（会和营业执照比对） |
| 法人信息 | 姓名、身份证号、手机号 |

### 第 3 步：填写网站信息

| 字段 | 怎么填 | ⚠️ 注意 |
|---|---|---|
| 网站名称 | **小鱼来了** | **不能带「中国」「国家」「新闻」「政府」等敏感词** |
| 网站域名 | xiaoyulaile.online | 只能填已验证实名的域名 |
| 网站服务内容 | **其他** / 信息服务 | **不要选「新闻」**（选了要新闻许可证） |
| 网站语言 | 中文简体 | |
| 前置审批 | 选「无」 | 若有新闻/出版/医疗等选对应 |

**🔥 最容易驳回的地方：网站服务内容选错。**

```
✅ 选：其他 / 信息服务 / 企业服务
❌ 不要选：新闻、出版、教育、医疗、金融
```

### 第 4 步：上传材料

```
□ 营业执照扫描件（清晰、四角完整）
□ 法人身份证正反面
□ 网站备案真实性核验单（下载打印、签字、拍照上传）
□ 域名证书
```

### 第 5 步：人脸核验

- 法人用手机里的备案 App 做**人脸识别**
- 必须在光线好的地方，正脸，不能戴帽子

### 第 6 步：提交审核

```
阿里云初审  1~2 个工作日（会打电话核实）
通信管理局审核  7~20 个工作日
```

**电话一定要接！** 阿里云和管局都会打电话核实，漏接会驳回。

---

## 五、审核期会问你什么（提前准备答案）

| 问题 | 标准答法 |
|---|---|
| 「网站是做什么的？」 | 「一个产业信息发布平台，企业可以发布项目、供需信息，用户可以浏览和检索。」 |
| 「有没有新闻内容？」 | 「**只有企业自己发布的信息摘要和原文链接，不做新闻采编。**」（这一点必须咬死） |
| 「有没有收费？」 | 备案期间答：「**目前免费，未开通支付。**」 |
| 「服务器买了多久？」 | 按实际答（必须 ≥3 个月） |
| 「为什么网站名和公司名不一样？」 | 「小鱼来了是产品名，公司名是注册主体名。」 |

## 六、备案期间网站要关吗？

**不用关。** 但要做三件事：

### ① 把资讯全文收敛掉

```
已完成：资讯只留「标题 + 摘要 + 原文链接」，
详情页不再展示全文，管理员仍可看全文。
```

> 这是最关键的准备。备案人员如果看到你全文转载媒体新闻，会要求你提供「互联网新闻信息服务许可证」。

### ② 首页挂上备案相关要素

```
✅ 已做：隐私政策 / 用户协议 / 免责声明 / 举报入口 / 运营主体 / 联系方式
⬜ 待办：备案号下来后，页脚加「沪ICP备XXXXXXXX号」
```

### ③ 检查有没有敏感功能表述

```
自查清单：
□ 「一键群发到微信群」→ 改成「生成转发文案」（避免被判定诱导分享）
□ 「保证对接成功」→ 删掉
□ 「投资」「回报」→ 检查有没有承诺收益的表述
□ 用户发布的内容有没有人工审核机制（要有）
```

## 七、备案通过后（我要做的事）

```
第 1 步  拿到备案号（如：沪ICP备2026XXXXXX号-1）
第 2 步  页脚加备案号，链接到 beian.miit.gov.cn
第 3 步  把服务迁移到大陆服务器（我远程操作，半天完成）
         · 代码同步（git pull）
         · 数据迁移（打包 /opt/xiaoyu-laile/data）
         · 环境搭建（node、nginx、证书）
         · DNS 切换
第 4 步  测速 + 回归测试
第 5 步  （可选）再买一台香港服务器做海外访问
```

**迁移当天的注意点：**

```
· 选在流量低峰（凌晨 2-4 点）
· 先切 DNS 的 TTL 到 60 秒（提前一天做）
· 迁移前做一次全量备份
· 迁移后观察 24 小时日志
```

## 八、常见驳回原因与对策

| 驳回原因 | 对策 |
|---|---|
| **网站名含敏感词** | 改成「小鱼来了产业信息平台」之类，去掉「中国」「新闻」 |
| **服务内容选了新闻** | 改成「其他」 |
| **域名实名主体与备案主体不一致** | 做域名过户 |
| **电话没接** | 重新提交，保持电话畅通 |
| **服务器不满 3 个月** | 续费到 3 个月以上 |
| **网站打不开** | 备案期间网站要能访问（可以先放个简单页面） |
| **网站有违规内容** | 删掉敏感内容（新闻全文、投资承诺等） |
| **地址不详 / 与执照不符** | 按营业执照地址填 |
