# 数字版权登记手册（小鱼来了）

> 用途：给「小鱼来了」这个作品做版权登记，拿到官方证书。
> 适用对象：运营主体（小鱼来了科技有限公司）法人或经办人
> 最后更新：2026-11-04

---

## 一、先分清三种「版权登记」

很多人把这三个混为一谈，实际用途不同、办理机构也不同：

| 类型 | 全称 | 办什么 | 办理机构 | 周期 | 费用 |
|---|---|---|---|---|---|
| **① 软件著作权（软著）** | 计算机软件著作权登记 | 登记「程序代码」这个作品 | 中国版权保护中心 | 30~60 个工作日（可加急） | 官方免费，加急需服务费 |
| **② 作品著作权（数字作品）** | 作品自愿登记（文字/美术/摄影/视听） | 登记「网站设计、文案、图片、宣传片」这类作品 | 中国版权保护中心 / 各省版权局 | 20~40 个工作日 | 多数省份免费 |
| **③ DCI 数字版权唯一标识** | 数字版权唯一标识符 | 给数字作品发一个链上/数据库里的唯一编号，可在线存证 | 中国版权保护中心 DCI 体系 | 1~7 个工作日（线上） | 按件计费，几十到几百元 |

**结论建议：**

```
第一步：软著（② 里的核心，也是最有用的）
    —— 代码作品，用于证明「这个系统是我们开发的」
    现有材料已经准备好了：soft-copyright/ 目录

第二步：作品著作权（网站页面设计 + 文案）
    —— 保护「界面长什么样、文案怎么写」

第三步（可选）：DCI 存证
    —— 需要快速出证、或者要上链时间戳时再做
```

## 二、软著（已有材料，直接办）

### 2.1 你要提交的东西（4 样）

```
① 申请表          → soft-copyright/软著申请表-填写内容.docx（已生成）
② 源程序 60 页    → soft-copyright/源程序文档.docx（已生成，前 30 页 + 后 30 页）
③ 软件说明书      → soft-copyright/软件说明书.docx（已生成）
④ 身份证明        → 营业执照副本扫描件
```

**重新生成方式（代码改动后要更新）：**

```bash
python scripts/gen-copyright-form.py     # 申请表 → docx
python scripts/gen-copyright-source.py   # 源程序 60 页
python scripts/gen-copyright-manual.py   # 软件说明书
```

### 2.2 办理步骤

```
1. 打开 中国版权保护中心 官网：https://www.ccopyright.com.cn
2. 注册账号（企业实名）
3. 「软件著作权登记」→ 在线填报
   · 软件全称：小鱼来了产业信息发布平台软件
   · 简称：小鱼来了
   · 版本号：V1.0
   · 开发完成日期：2026-XX-XX
   · 首次发表日期：2026-XX-XX（或选「未发表」）
   · 权利取得方式：原始取得
   · 权利范围：全部权利
4. 上传 ②③ 两个 PDF/DOCX（源程序 + 说明书）
5. 提交 → 等受理通知 → 邮寄纸质材料（部分地区全电子）
6. 30~60 个工作日下证
```

**加急渠道：** 官方有加急服务（3/5/10 个工作日），费用几百到一千多；也可以找代理（收费更高但省事）。

### 2.3 常见退回原因（提前避坑）

```
✗ 源程序页数不够 60 页 → 每页 50 行，前 30 页 + 后 30 页
✗ 代码里有大段空行/注释凑页数 → 会被要求重做
✗ 说明书里没有「功能模块图 / 流程图」 → 建议补两张
✗ 软件名称里带「平台」「系统」但说明书写成网站 → 口径要一致
✗ 申请表里的日期与说明书里写的对不上
```

## 三、作品著作权登记（网站页面 + 文案）

### 3.1 登记什么

可以拆成几件分别登记（每件一张证）：

| 作品 | 类型 | 材料 |
|---|---|---|
| 小鱼来了首页界面设计 | 美术作品（或图形作品） | 页面截图（高清）+ 设计说明 |
| 小鱼来了品牌 LOGO | 美术作品 | LOGO 矢量图 + 设计说明 |
| 「让每一条好项目，都被对的人看见」等宣传文案 | 文字作品 | 文案全文 + 创作说明 |
| 平台宣传短视频 | 视听作品 | 视频文件 + 脚本 |

### 3.2 办理步骤

```
线上：中国版权保护中心「作品著作权登记」
      或 各省版权局「作品自愿登记」（多数免费）
    ↓
填表：作品名称、类别、创作完成日期、首次发表信息
    ↓
上传：作品样本（截图/图片/文档）+ 作品说明书（300 字左右）
    ↓
审核 20~40 个工作日 → 下发《作品登记证书》
```

### 3.3 作品说明怎么写（模板）

```
作品名称：小鱼来了产业信息发布平台首页界面设计
作品类别：美术作品
创作完成日期：2026-XX-XX
首次发表日期：2026-XX-XX（在本站 www.xiaoyulaile.online 发表）

创作说明：
  本作品为产业信息发布平台的移动端首页界面设计，采用蓝绿渐变主色，
  以「搜索—发布—浏览」为主路径，包含 AI 搜索入口、发布横栏、
  活动与赛事专区、项目卡片流等模块。设计目标是让中小企业用户
  在 3 次点击内完成「找到项目 / 发布需求」两个核心动作。
  界面中的图标、配色、卡片圆角与投影均为原创设计。
```

## 四、DCI 数字版权存证（想要快证时用）

### 4.1 是什么

中国版权保护中心的数字版权唯一标识体系，给作品发一个 **DCI 码**，
在线提交、快速出证，可作为「某时间点已存在该作品」的证据。

### 4.2 适合登记什么

```
· 网站页面设计稿
· 原创图片 / 海报
· 原创短视频
· 原创文章 / 文案
```

### 4.3 步骤

```
1. 打开 https://www.dci.ccopyright.com.cn（中国版权保护中心 DCI 门户）
2. 企业实名注册
3. 选择「作品存证 / 登记」
4. 上传作品文件 + 填写作品信息
5. 在线支付（按件）
6. 1~7 个工作日拿到 DCI 码与电子证书
```

## 五、三种登记怎么排优先级（钱和时间的角度）

| 顺序 | 做什么 | 为什么 | 时间 | 花费 |
|---|---|---|---|---|
| **1** | **软著** | 证明「系统是我们开发的」，上架应用商店、投标、融资都要 | 30~60 天 | 官方免费（加急另算） |
| 2 | 首页界面作品登记 | 防别人抄界面，成本低 | 20~40 天 | 多数省份免费 |
| 3 | DCI 存证 | 要快速出证、或需要时间戳证据时 | 1~7 天 | 几十~几百元/件 |
| 4 | 商标注册 | 保护「小鱼来了」这个名字（**和版权是两回事**） | 6~12 个月 | 300 元/类 |

**特别提醒：版权登记 ≠ 商标注册。**

```
版权：证明「这个作品是我创作的」
商标：证明「这个名字在某个类别归我用」
两者都要做，缺一不可。
```

**商标建议现在就去申请（周期长，越早越好）：**

```
类别建议：
  第 35 类（广告、商业信息、商业中介）  ← 核心
  第 42 类（软件服务、平台技术服务）
  第 9 类（可下载软件）
  第 36 类（金融信息、投资咨询）
```

## 六、材料齐全性检查清单

### 软著

```
□ 营业执照副本扫描件（清晰、四角完整）

□ 软件说明书（含功能模块图、流程图、界面截图）
□ 软件名称、版本号、开发/发表日期已确认且前后一致
```

### 作品著作权

```
□ 作品样本（高清截图 / 源文件）
□ 作品说明书（300 字左右，讲清创作过程与独创性）
□ 首次发表证明（本站 URL + 发表日期截图）
□ 营业执照副本
```

### DCI

```
□ 作品文件（原始格式）
□ 作品基本信息（名称、类别、创作完成时间）
□ 企业实名信息
```
