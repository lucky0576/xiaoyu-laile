# 小鱼来了 · 付费转化话术

> 用途：一对一私聊那 20 个「发过项目」的用户，验证付费意愿。
> 目标：两周内拿到 3 个付费客户，收入 5000 元以上。
> 原则：**先说清为什么收钱，再说权益，最后才说价格。**

---

## 一、先明确：你要卖给谁

**不是所有 200 个用户，是这 20 个人：**

```
筛选标准（按优先级）：
① 发布过 3 条以上项目信息的人        ← 最可能有真实业务
② 发布过 1 条但内容完整的（有预算/联系方式）
③ 反复浏览、收藏但没发过的
```

**不要群发广告。** 一对一，带上他的名字和他发过的项目名。

---

## 二、开场（三种，按关系远近选）

### 版本 A：你和他聊过天

```
XX 总，我是小鱼来了的老卢。
你上个月发的那条「XXX 项目」，最近有三个人点进去看过，
其中一个还申请了联系方式。

想跟你聊件事：平台准备开启付费了，想先听听你的意见。
方便的时候给我回个话？
```

### 版本 B：没聊过，但他发过项目

```
XX 你好，我是小鱼来了的卢云。
看到你 10 月发过「XXX」这条项目，想跟你确认一下：
后来有对接到合适的人吗？

另外想问你个事，平台现在要开始收一点费用维持运营，
想听听你这种实际在做事的人怎么看，不买也没关系。
```

### 版本 C：他在平台上很活跃

```
XX，我是小鱼来了的卢云。
注意到你最近一直在看江浙沪那边的项目，也发过几条。

想请你说句实话：现在这个平台对你有没有用？
如果开始收费，你觉得值多少？
```

**关键：先问他的问题，不要一上来就卖。**

---

## 三、他问「为什么要收费」——这么答

```
说实话，平台是我一个人做的，服务器和 AI 每月都在花钱。
现在全免费能撑，但撑不了太久。

我不想做成那种收广告费的平台（那样信息质量就完了），
所以想改成「用的人付一点钱」，把服务做好。

你愿意付，我就把你的事当正事办；
你不愿意付，我也不勉强，免费功能照旧能用。
```

**这段话的核心：诚实 + 不跪。** 用户能感觉到你是不是在骗他。

---

## 四、讲权益（一次只讲三条，讲他关心的）

### 如果他关心「能不能找到人」

```
专业版（199 元/月）主要解决三件事：

① 你的信息会排在列表前面 —— 现在一天发几十条，
   不置顶很快就被刷下去
② 联系方式对「已申请对接」的人自动可见 ——
   不用每次你自己回微信
③ AI 帮你把项目要素整理成结构化字段，
   对方一看就知道你是不是他要找的
```

### 如果他关心「发出去没人看」

```
现在平台每天有三百多次浏览，但你的信息淹没在里面。

专业版会让你进「优先推荐」，我另外会人工帮你转一次
到我手上的几个产业群 —— 这个是我私下帮你，
不是系统功能。
```

### 如果他关心「值不值这个钱」

```
你可以先试一个月。29 元入门版，或者 199 元专业版。

我建议你先用入门版试试，觉得有用再升级，
别一上来就买贵的。
```

**主动推荐便宜的那档。** 这会让他觉得你在替他省钱，成交率反而高。

---

## 五、报价与成交

### 报价格式（必须先说年付）

```
价格是这样的：
  入门版  29 元/月，年付 299
  专业版  199 元/月，年付 1999（相当于付 10 个月）
  团队版  499 元/月，年付 4999

我建议你按年付，因为按月很多人第二个月就忘了续。
而且年付我可以多给你一次人工撮合。
```

### 成交动作（别留悬空）

```
那就这么定：
1. 你在「我的 → 会员」里点开通
2. 扫码或转账，付完点「我已付款」
3. 我这边确认到账，一般一小时内给你开通
4. 开通后我帮你把「XXX」那条调成优先推荐
```

**每一步都说清楚，不要让他自己去研究。**

---

## 六、被拒绝怎么办（六种常见回答）

### ① 「太贵了」

```
理解。那你觉得多少合适？
如果 99 元一年你能接受，我按这个给你开，
但我得说清楚：这是老用户价，后面不会有了。
```

### ② 「我没钱 / 生意不好做」

```
明白，现在生意确实难。
这样，你先免费用着，我不催你。
等我这边有合适的项目对接机会，我先想到你。
```

**不要纠缠。留个好人缘，他以后有钱会回来。**

### ③ 「平台没给我带来客户」

```
这句话对我很重要，你能具体说说吗？
是发出去没人看，还是有人看了但没联系上？

如果是前者，是我推荐机制没做好；
如果是后者，我看看是不是联系方式那块卡住了。
```

**这是最有价值的一类反馈，比拒绝值钱。**

### ④ 「你自己做的平台，凭什么收钱」

```
凭两点：一是我把信息整理出来了，你能搜到；
二是我在帮人对接，不是只挂个页面。

你要是觉得没用，不用付，真的。
```

### ⑤ 「等别人用了再说 / 我再看看」

```
行，不急。我先把你的信息调到前面试试效果，
两周后我再问你一次，有没有变化。
```

**设一个回访时间点，不要无限期悬着。**

### ⑥ 「能不能给我免费」

```
可以给你一个月试用，条件是：用完告诉我值不值。
如果没价值，你不用付；如果有价值，你按年付买。
```

## 七、每天做多少（执行节奏）

```
每天私聊 3~5 个人，不要多。
  早上 9-10 点：发 2 条（老板刚上班看手机）
  晚上 8-9 点：发 2 条（饭后刷手机）

两周 = 20 个用户 ≈ 40 条消息 ≈ 10 个回复 ≈ 3 个成交
```

**记录表（自己用 Excel 记）**：

| 姓名 | 项目 | 是否回复 | 是否问价 | 是否成交 | 拒绝原因 |
|---|---|---|---|---|---|
| 张总 | 苏州医院装修 | 是 | 是 | 是 | — |
| 李总 | 储能电站 | 否 | — | — | — |

**这个表是以后融资时的「付费意愿验证数据」，比任何 PPT 都硬。**

---

## 八、三条红线

| 不能做 | 原因 |
|---|---|
| ❌ 群发广告 | 用户会直接拉黑，且微信判定营销号 |
| ❌ 吹嘘「保证对接成功」 | 做不到就是欺诈 |
| ❌ 承诺「投资」「高回报」 | 涉嫌非法集资表述 |

---

## 九、成交之后立刻做三件事

```
① 当天开通，不要拖
② 微信发一句：「已开通，你的项目我调成优先推荐了」
③ 一周后回访：「这一个星期有人联系你吗？」
```

**第三件事最重要。** 它决定了他会不会续费。
