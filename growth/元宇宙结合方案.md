# 小鱼来了 × 元宇宙：怎么结合（方案 v1）

> 结论先说：**可以结合，而且不用从零做一个「通用元宇宙」**。
> 小鱼来了已经有真实产业数据、AI 内容生产、短视频/短剧、直播会议、强脑科技（脑机接口/机器人）合作，
> 这些正好是元宇宙里最缺的「真内容」和「真场景」。要做的只是加一层 **Web 3D / VR 展示**，
> 把「看信息」升级成「进场景看项目」。

---

## 一、先明确：不做什么

```
✗ 不做通用社交元宇宙（烧钱、没场景、不赚钱）
✗ 不做重客户端（UE/Unity 包体大，用户不会下载）
✗ 不做虚拟地产/炒地皮（政策风险 + 没有真实价值）
```

**只做「产业元宇宙」：项目、园区、工厂、设备、课程的可视化展示与对接。**

---

## 二、五个能落地的结合点（按投入产出排序）

### ① 产业元宇宙展厅（最优先，直接可卖钱）

```
场景：把一条项目 / 一个园区 / 一个工厂做成 3D 展厅
  · 3D 场景（WebGL / glTF 模型）
  · 场景里放「信息卡」：项目标题、金额、资质、联系方式（脱敏）
  · 点信息卡 → 回到现有项目详情页 → 对接/留言（复用现有成交链路）
  · 手机可直接看，VR 眼镜打开就是沉浸模式（WebXR）

卖给谁：
  · 园区 / 政府招商：一个园区 3D 展厅 10~30 万
  · 企业展厅 / 工厂：5~15 万
  · 强脑科技：脑机接口 + 机器人 3D 展项（与设备打包）
```

### ② VR 看厂 / 远程验厂

```
场景：EPC、设备采购、光伏/储能项目，买方要实地看
  · 360° 全景 + 3D 漫游 + AI 语音讲解（复用 CosyVoice 声音）
  · 关键设备打点：参数、报价、交付周期
  · 按次收费 / 会员免费看
定价：单次 500~2000 元，年费会员 3000~10000 元
```

### ③ 数字人主理人（城市 / 行业）

```
场景：每个城市或行业的主理人，有一个 3D 数字人分身
  · 24 小时讲解本地项目、接待来访、回答常见问题
  · 声音用本人音色（声音复刻，需授权）
  · 主理人可把这套数字人作为「自己的线上展厅」
收费：数字人主理人年费 3000~10000 元（含 3D 形象 + 声音 + 场景）
```

### ④ 脑机接口 + 元宇宙互动（和强脑科技结合，差异化最强）

```
场景：脑电/专注力控制虚拟展厅、意念控制机器人/虚拟形象
  · BCIGo 32 通道脑电 + SSVEP/MI 范式 → 控制 3D 场景中的机器人或分身
  · Revo 灵巧手 / RevoTron 双臂机器人 → 3D 数字孪生同步动作
  · 落地：科技馆、高校创践中心、园区展示中心、招商路演
打包：强脑设备 + 小鱼来了 3D 互动内容，5~20 万/套
```

### ⑤ 虚拟制片 + 短剧

```
场景：短剧不用实景，直接在 3D 虚拟场景里拍
  · 现有短剧频道 + 虚拟场景 → 降本、可批量
  · 产业题材短剧（工厂、项目、创业）用虚拟场景更可控
  · AI 生成场景 + 数字人演员（合规标注「演绎」）
```

## 三、技术方案（轻量、可控、不增加运维负担）

```
前端（Web 优先，手机即用）
  · Three.js / Babylon.js（WebGL）+ WebXR（VR 眼镜直接打开）
  · glTF 模型资产（通用格式，可压缩到几 MB）
  · 3D 场景嵌入现有 SPA：#/metaverse/:sceneId
  · 手机浏览器直接看 3D，不需要装 App

后端（复用现有 Node 服务）
  · scenes 集合：场景配置、模型地址、信息卡锚点
  · 与 listings 关联：场景里的信息卡直接指向现有项目
  · 文件服务复用（模型/全景图/音频）

内容生产（用 AI 降本）
  · 全景图 → 手机拍摄 + 拼接
  · 简单场景 → Blender 建低模 + glTF 导出
  · text-to-3D / AI 生成概念场景（辅助）
  · 讲解词 → 复用现有 AI 生成 + CosyVoice 配音

硬件（与强脑合作，不自研）
  · VR 眼镜：Quest / PICO / 国产一体机
  · 脑电：强脑 BCIGo 32 通道
  · 机器人：强脑 RevoTron / Revo 灵巧手
```

## 四、分阶段路线（先做能卖钱的）

### 第 1 步：3D 产业展厅 MVP（1~2 周）

```
· #/metaverse 展厅列表
· 一个样板场景：杭州上城区产业元宇宙展厅（接入现有 235 条项目里的 20 条）
· 场景里 3D 信息卡 → 点开回到项目详情页
· 手机可看 + 分享链接 + 二维码
验收：手机打开能 3D 漫游、点项目能进详情、链接可分享
```

### 第 2 步：数字人讲解 + VR 模式（2~3 周）

```
· 数字人站在展厅里讲解（复用 TTS，后续声音复刻）
· WebXR 一键进 VR（手机放眼镜盒 / 一体机）
· 全景看厂场景
```

### 第 3 步：强脑脑机互动展项（1 个月，与强脑联合）

```
· 脑电控制虚拟展厅灯光/机械臂/分身
· 数字孪生：真实机器人动作同步到 3D
· 打包成「脑机元宇宙展项」卖给科技馆/高校/园区
```

### 第 4 步：虚拟制片短剧（按需）

```
· 3D 场景 + 数字人 → 短剧频道
```

## 六、风险与规避

```
① 硬件不普及 → 手机 3D 优先，VR 只是增强，不依赖
② 内容生产成本高 → 先做全景 + 低模，不做精模；AI 辅助
③ 用户不来 → 展厅挂在项目详情页/短视频/群发链接里，作为「看项目的新方式」
④ 政策风险 → 不做虚拟货币、不做虚拟地产、不做匿名社交
⑤ 变成纯展示不成交 → 每个场景必须带「信息卡 → 项目详情 → 对接」闭环
```

## 七、一句话总结

```
小鱼来了的元宇宙 = 「产业展厅 + 数字人 + 脑机互动」，
不卖虚拟世界，卖「让项目方、园区、政府更好展示和成交」的工具；
用 Web 3D 做轻量展示，用真实产业数据做内容，用强脑科技做差异化硬件。
```
