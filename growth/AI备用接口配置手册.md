> 用途：主接口（硅基流动）欠费或限流时，AI 自动切到备用接口，用户不会看到「AI 调用失败」。
> 适用对象：平台管理员（只需要做一次，约 10 分钟）
> 最后更新：2026-11-04

## 三、智谱注册（5 分钟）

### 第 1 步：打开官网

浏览器访问：**https://bigmodel.cn**（智谱开放平台，原 open.bigmodel.cn）

> 手机上也能操作，但复制 Key 用电脑更方便。

### 第 2 步：注册账号

```
首页右上角「登录 / 注册」
   ↓
选「手机号注册」
   ↓
输入手机号 → 获取验证码 → 填验证码
   ↓
设置密码 → 完成注册
```

**注意：这里用的是你**自己的手机号**，一个手机号一个账号，不要用别人的。**

### 第 3 步：实名认证（必须做，否则调不了接口）

```
登录后 → 右上角头像 → 「实名认证」
   ↓
选「个人实名」→ 填姓名 + 身份证号
   ↓
按提示完成人脸或银行卡验证
   ↓
等待审核（一般几分钟到几小时）
```

> 如果提示「企业认证」，个人账号选个人实名就行。

### 第 4 步：创建 API Key

```
登录后 → 右上角头像 → 「API Keys」（或「密钥管理」）
   ↓
点「新建 API Key」
   ↓
名称随便填：小鱼来了
   ↓
创建成功 → 立刻点「复制」
```

**Key 长这样：**

```
1a2b3c4d5e6f7890.ABCDEFGHIJKLMNOP
       ↑ 中间有一个「.」分隔
```

⚠️ **三个坑，务必注意：**

```
1. 中间那个「.」不能漏 —— 漏了就鉴权失败
2. 前后不能有空格
3. 这个 Key 只显示一次，关掉页面就看不到了
   → 复制后先粘到记事本存好
```

### 第 5 步：确认有免费模型可用

```
左侧菜单 → 「模型广场」→ 搜「glm-4-flash」
   ↓
能看到「glm-4-flash」就是可以用（免费模型）
```

**记下名字：`glm-4-flash`（全小写，中间是短横线，不要写成 glm4flash）**

## 七、常见问题

### Q1：保存后还是报「AI 接口鉴权失败」

```
检查 Key 是不是复制完整：
  · 中间有「.」吗？
  · 前后有空格吗？
  · 是不是复制成了别的（比如账号 ID）？

重新复制一次，粘贴到记事本对比长度（一般 40~60 个字符）
```

### Q2：报「模型不存在」或「model not found」

```
模型名必须完全一致：glm-4-flash
  ✗ GLM-4-Flash（大小写）
  ✗ glm4flash（少了短横线）
  ✗ glm-4-plus（这是付费模型）
```

### Q3：报「该模型已下线」或「无权限」

```
去「模型广场」搜 glm-4-flash，确认还能用；
或者换成 glm-4-air（有免费额度）、glm-4-plus（付费）
```

### Q4：报 429 / 限流

```
免费模型有调用频率限制。
正常使用不会碰到；如果你连续点「AI 生成」十几次，
等 1 分钟再试即可。
系统遇到 429 会自动切到内置免费通道，不会中断。
```

### Q5：填了备用接口，主接口还需要管吗

```
不用改主接口。
调用顺序是：主接口 → 备用接口 → 内置免费通道 → 规则引擎
主接口欠费就自动跳过，不影响使用。
等哪天给硅基流动充了钱，主接口自动恢复优先。
```

### Q6：Key 会泄露吗

```
· 后台保存后不会回显完整 Key（只显示前 6 位 + 后 4 位）
· Key 存在服务器 data/settings.json，不进 git、不进发布包
· 如果怀疑泄露：去智谱控制台删掉这个 Key，重新建一个再填一遍
```

## 八、其他免费方案

### 方案 B：OpenRouter 免费模型

```
1. https://openrouter.ai 用邮箱注册
2. Keys 页面 → Create Key
3. 后台备用接口填：
     地址：https://openrouter.ai/api/v1
     模型：meta-llama/llama-3.1-8b-instruct:free
     Key：  sk-or-v1-xxxx
```

**优点：免费模型多，可换。缺点：国内访问不稳，偶尔超时。**

### 方案 C：本地 Ollama（完全免费，不要任何账号）

```
1. 电脑装 Ollama：https://ollama.com/download
2. 命令行拉模型：ollama pull qwen2.5:7b
3. 确认在跑：浏览器打开 http://127.0.0.1:11434 看到 "Ollama is running"
4. 后台备用接口填：
     地址：http://127.0.0.1:11434/v1
     模型：qwen2.5:7b
     Key：  留空
```

**注意：这条路是「谁打开网页谁用自己的电脑算」，只有你自己电脑开着才有效。
不适合给用户用，只适合你自己测试。**

### 方案 D：给硅基流动充值

```
https://siliconflow.cn → 费用中心 → 充值 50 元
按现在的用量（每次汇总约 0.001~0.01 元）能用很久
充完什么都不用改，主接口自动恢复
```
