# 小鱼来了 · 企业服务报价单

> 面向：政府招商部门 / 产业园区 / 产业基金 / 中小企业
> 用途：单笔 1~10 万的合同，走对公，可开专票。
> 原则：**不报裸价，报方案；不讲技术，讲他能得到什么。**

## 一、四个标准方案

### 方案 A｜私有化部署（最推荐）

**适合**：政府、园区、国企、数据不能出内网的机构

| 项 | 内容 |
|---|---|
| **交付物** | 完整平台源码部署到客户服务器（客户自己买服务器） |
| **部署范围** | 全部功能：信息发布、检索、AI 解析、招投标采集、会员管理 |
| **数据** | 完全在客户内网，我们不接触任何数据 |
| **交付周期** | 5 个工作日 |
| **包含服务** | 部署 + 初始化 + 2 小时培训 + 3 个月免费运维 |
| **报价** | **3.8 万 / 年**（首年含部署 5 万） |

**为什么这个价**：
- 市面上同类政务信息化项目 20 万起
- 我们的优势是**零第三方依赖**，能塞进任何一台 2 核 2G 的机器，不用额外买数据库授权

## 三、怎么开口（三种场景）

### 场景 1：见到园区/招商局的人

```
对方：你们这个平台是做什么的？
你：  帮园区把项目信息结构化，让外面的人能搜到、能对接。
     现在很多园区招商还在用 Word 和 Excel，信息发出去就沉了。

对方：怎么合作？
你：  两种。一种是你们用我们的平台，年费一万八；
     一种是装到你们自己的服务器上，数据不出内网，三万八一年。

对方：能试用吗？
你：  可以，我先给贵方开一个月的账号，你们看数据质量。
     （← 这一步最重要，先给账号，别急着报价）
```

### 场景 2：见到企业老板

```
你：  张总，你们平时项目信息怎么发出去的？
对方：就发朋友圈，或者微信群。
你：  发出去有人找你们吗？
对方：有是有，但不多，也不好筛。
你：  我帮你整理一下，结构化发到平台上，
     另外我手上有几个产业群，帮你转一次。
     一个月三千，你试试？
```

**对小客户不要讲「私有化部署」，讲「帮你发信息」。**

### 场景 3：见到投资机构

```
你：  你们看项目，尽调阶段是不是要花很多时间在信息收集上？
对方：对，尤其是早期项目，公开信息很少。
你：  我们做了一份单项目分析，你先看看质量。
     （← 免费给一份，让他看到价值）
     如果合适，长期合作的话 800 一份，或者直接订阅我们的库。
```

## 四、定价的三条心理原则

### ① 不要报「整数万」

```
❌ 40000 元
✅ 38000 元
理由：38000 看起来是算过的，40000 看起来是拍的
```

### ② 给三个选项，不要给一个

```
年费方案：
  基础版 1.8 万
  标准版 3.8 万   ← 你希望他选这个
  旗舰版 8 万

中间那档最容易成交。
```

### ③ 先说「能退」，再说价格

```
「先用一个月，不满意全额退。」
这句话能把成交率提高一倍，实际退款率很低。
```

## 五、必须提前准备的四样东西

| 材料 | 状态 | 说明 |
|---|---|---|
| **营业执照** | ⬜ 待办 | 个体户或公司，签合同必须有 |
| **软件著作权证书** | 🟡 已申请 | 政府项目要这个 |
| **案例 / 演示账号** | ✅ 已有 | 就是现在的平台 |
| **发票能力** | ⬜ 待办 | 个体户可开普票，公司可开专票 |

**没有前两样，政府类客户基本谈不成。**

## 六、报价的红线

| 不能做 | 原因 |
|---|---|
| ❌ 承诺「保证招到商」 | 做不到就是违约 |
| ❌ 卖「新闻信息服务」 | 需要许可证 |
| ❌ 把采集的数据单独倒卖 | 数据来源是公开渠道，倒卖有风险 |
| ❌ 不开票收款 | 客户无法入账，且你有税务风险 |

**正确姿势：卖服务（部署、运营、分析），不卖数据本身。**
