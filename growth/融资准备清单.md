## 3. Financial Model / 财务模型（Excel 三个表就够）

```
Sheet 1 — Revenue build
   客户数 × 客单价 × 复购，按月推 18 个月
   三条收入线分开：企业服务 / 主理人年费 / 广告

Sheet 2 — Cost
   人力（先算你 + 3 个岗位）
   服务器与带宽
   内容制作（短视频/短剧）
   合规（备案、软著、律师）

Sheet 3 — Cash
   现金余额、跑道（runway）月数
   融资到账后跑道延长到多少
```

**关键数字投资人一定会问：**

- 客单价多少？
- 获客成本（CAC）多少？
- 一个客户能活多久（LTV）？
- 毛利率？（信息平台应该 >80%）

**你现在能答的：** 客单价 ¥800 ~ ¥300,000（分档）；CAC 未知（靠人脉）；
毛利率接近 100%（除了服务器）。**不知道就直说。**

## 5. Structure: onshore vs offshore / 主体结构

**现在：** 小鱼来了科技有限公司（中国境内）

**如果拿美元基金，通常需要：**

```
开曼公司（Cayman）作为融资主体
    ↓ 100% 持股
香港公司（HK holding）
    ↓ WFOE（外商独资）
境内运营公司（现有主体）
```

**成本：** 开曼 + 香港 + WFOE 搭建约 5~15 万人民币，每年维护 3~5 万。

**建议：**

```
拿人民币基金 / 政府基金 / 产业资本 → 不需要搭海外架构，别花这个钱
拿美元基金 → 再搭，通常投资人会帮你找律所
```
