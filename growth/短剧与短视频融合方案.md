# 短视频 × 短剧：怎么结合（产品 + 技术 + 商业化方案）

> 背景：平台已经有「短视频」能力（每条信息 → 5/10/30 秒竖版视频，真实数据 + AI 语音 + 自动配图），
> 下一步要把「短剧」接进来，形成「短视频拉新 → 短剧留人 → 信息卡转化」的闭环。
> 本文档给的是可落地的方案，不是概念。

---

## 一、一句话结论

```
短视频 = 每一条项目信息的「广告片」（真实、短、直接）
短剧   = 由真实项目改编的「连续剧情」（虚构标注、可追更、可传播）
两者共用同一套生产管线，短剧负责流量和停留，短视频负责转化和成交。
```

---

## 二、产品形态：三个结合点

### 1. 首页/短视频流里「穿插」短剧

```
用户刷短视频（项目广告片）→ 刷到第 5 条时插入一集短剧
  · 短剧每集 30~60 秒，结尾 3 秒「信息卡」：真实项目标题 + 城市行业（无二维码、无电话，符合现有要求）
  · 用户点信息卡 → 直达项目详情页（这就是转化）
  · 短剧带「追剧」按钮 → 关注后更新推送
```

### 2. 短剧合集页（剧集 = 一个项目/一个行业/一个城市的故事线）

```
#/drama              → 短剧频道首页（推荐、热播、追更）
#/drama/:seriesId    → 剧集合集（第 1~N 集，自动连播）
```

示例剧集（全部由真实项目改编，片头标注「项目改编 · 演绎」）：

| 剧集 | 集数 | 改编来源 | 目的 |
|---|---|---|---|
| 《200MW 的赌局》 | 6 集 | 东营渔光互补 EPC 项目 | 展示 EPC 项目全流程 |
| 《算力争夺战》 | 8 集 | 长三角智算中心 2000 机柜招商 | 算力消纳获客 |
| 《35 岁的新工作》 | 10 集 | 35+ 主理人真实故事 | 招 1000 位 35+ 合作人 |
| 《宁波老板的越南订单》 | 5 集 | 跨境贸易项目 | 贸易板块获客 |

### 3. 项目详情页：短视频 + 剧集联动

```
项目详情页加「看这个项目的短剧」入口
  · 有短剧 → 播放对应剧集
  · 没有 → 「让 AI 生成一段剧情短片（30 秒）」按钮，项目方付费 $9.9/条
```

## 三、技术怎么实现（复用现有能力，不重新造）

### 3.1 数据模型

```js
// 新增集合：dramas.json
{
  id: 'dr_xxx',
  title: '200MW 的赌局',
  subtitle: '真实项目改编 · 演绎',
  listingId: 'l_xxx',        // 改编来源（可空）
  seriesNo: 1,               // 第几集
  totalEpisodes: 6,
  coverUrl: '/files/...',
  videoFileId: 'f_xxx',      // 生成的 mp4
  durationSec: 45,
  status: 'published',
  views: 0, likes: 0, follows: 0,
  createdAt: '...'
}

// feeds 短视频流增加剧集字段
{ ...short, dramaId: 'dr_xxx', seriesNo: 1 }
```

### 3.2 生成管线（复用 make-short.js 的 ffmpeg 渲染）

```
项目信息（标题/正文/图片/视频）
   ↓ ① AI 脚本：把项目事实改写成 30~60 秒剧情脚本（对话/旁白）
   ↓ ② 分镜素材：项目图片 + AI 生图（可选）+ 已有短视频素材
   ↓ ③ 配音：Kokoro 中文神经语音（男/女声，按角色分配）
   ↓ ④ 渲染：ffmpeg 模板（片头钩子 3s + 剧情 + 片尾信息卡 3s + 字幕）
   ↓ ⑤ 落库：dramas + feeds，发布到短剧频道
```

**新增 `src/services/make-drama.js`**：
- `renderDrama({ listing, script, voiceMap, seconds })`：复用 `make-short.js` 的封面/裁剪/drawtext/TTS 能力
- 模板参数：片头钩子文案、剧集标题、集数、片尾信息卡（标题+城市行业，无二维码无电话）
- 合规：片头固定「项目改编 · 演绎」标注；不出现收益承诺、不出现真实联系方式

### 3.3 AI 脚本（新增 `dramaWrite`）

```
输入：项目标题、正文、行业、城市
输出 JSON：
{
  "title": "算力争夺战",
  "episodeTitle": "第 3 集：谁拿下了那 2000 个机柜",
  "hook": "招标还剩 72 小时…",
  "scenes": [
    { "narration": "……", "visual": "机房全景", "seconds": 8 },
    ...
  ],
  "infoCard": "长三角智算中心 2000 机柜招商 · 杭州"
}
```

**约束提示词**：只使用项目里已有的事实；不得编造价格/资质/联系方式；必须标注演绎。

### 3.4 前端改动

| 页面 | 改动 |
|---|---|
| `#/shorts` 短视频流 | 每 N 条插入一集短剧；卡片右上角加「短剧」标签；点进剧集 |
| `#/drama` 新增 | 短剧频道：推荐位、剧集列表、追更 |
| `#/drama/:id` 新增 | 剧集播放器：上下集、连播、追剧、分享 |
| 项目详情页 | 「看这个项目的短剧」/「生成剧情短片」按钮 |

## 四、商业化：短剧怎么赚钱

| 收入 | 方式 | 定价 |
|---|---|---|
| **项目定制短剧** | 项目方付费把自己的项目做成 3~6 集短剧 | 3,000~30,000 元/部 |
| **品牌/园区定制** | 政府、园区、产业带定制城市短剧 | 5 万~30 万/季 |
| **短剧贴片/插播广告** | 每集片头 5 秒贴片，或剧中信息卡 | CPM 30~80 元 |
| **短剧会员/解锁** | 第 1 集免费，后续需会员（谨慎，先用广告模式） | 9.9 元/月 |
| **引流成交** | 短剧 → 项目详情 → 企业服务成交（核心） | 按现有 9 条收入线 |

**和现有三引擎的关系：**

```
收费服务 ← 短剧引流来的客户
算力消耗 ← 短剧生成本身消耗算力（按条计费）
短视频/短剧广告 ← 短剧贴片 + 短视频信息流
```

## 五、合规红线（必须做）

```
① 片头/简介标注「项目改编 · 演绎」，不能让人误以为是真实纪实
② 不虚构项目金额、资质、政府关系、投资回报
③ 不出现真实联系方式（延续现有短视频规则：无二维码、无电话）
④ 微短剧内容需按平台规则审核；上线前人工过一遍
⑤ 涉及真人出镜/肖像，需授权
```

## 六、实施路径（分三步，先跑起来）

### 第一步：MVP（1~2 周）

```
· 短剧模板生成器：一条信息 → 30 秒剧情短片（单集，不是连续剧）
· 剧集数据结构 + 短剧频道页 #/drama
· 短视频流里插入短剧（每 8 条插 1 条）
· 先做 5 部样例短剧，用真实项目改编
验收：用户能在短视频流里刷到短剧并点进项目详情
```

### 第二步：连续剧 + 追更（2~3 周）

```
· 剧集管理：一个项目 3~6 集
· 追剧/更新通知（复用现有通知系统）
· 播放器连播、上下集
· 数据看板：完播率、追剧率、跳转率、成交线索
```

### 第三步：商业化 + 定制（1 个月）

```
· 项目方自助下单「定制短剧」（选模板、上传素材、付费）
· 贴片广告位接入
· 城市/园区定制剧
```

## 七、和现有短视频功能的具体结合点（代码层面）

| 现有能力 | 短剧怎么复用 |
|---|---|
| `make-short.js` ffmpeg 渲染（720×1280、标题烧字、TTS、无二维码） | 直接复用，增加「片头钩子」「片尾信息卡」两段 drawtext |
| `tts.js` Kokoro 男/女声 | 按角色分配音色（主角/旁白/客户） |
| `cover-auto.js` 自动配图 | 短剧封面自动生成（剧集号 + 标题） |
| `feeds` 短视频流 | 加 `dramaId/seriesNo` 字段，流里混排 |
| `notifications` 通知 | 追剧更新提醒 |
| `broadcast` 群发 | 短剧分享文案 + 长图（复用现有群发二维码规则） |
| `share` 分享 | 每集可单独分享，落地页带剧集信息 |

## 八、一句话回答「怎么结合」

```
用同一套生产管线（项目信息 → AI 脚本 → ffmpeg + 神经语音 → 竖版视频），
把「一条信息一条片」升级成「一个项目一部短剧」；
短剧放在短视频流里做流量和停留，片尾信息卡把观众送回项目详情页成交；
收费来自项目方定制、广告和算力消耗。
```
